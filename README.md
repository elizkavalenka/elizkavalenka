## 🤖 AI & Workflow

I treat AI as a **productivity multiplier** — never a replacement for engineering judgment.

- **GitHub Copilot** — inline code completion and boilerplate reduction in Angular/React components.
- **Claude & ChatGPT** — architectural discussions, refactoring complex logic, generating documentation, and accelerating debugging.
- **Human-in-the-loop validation** — all AI-generated code is verified with **ESLint**, **Stylelint**, and manual/peer code review.
- **Faster onboarding & delivery** — using AI to explore alternative solutions, write test cases, and reduce time spent on repetitive tasks.

> 💡 *Result: cleaner code, faster iteration, and more time invested in architecture, UX, and accessibility.*
